# opentmf-622-v4-model

This artifact holds the TMF-622 Product Ordering Management API model classes generated by the opentmf
code generator.

## Usage
In order to use this model library, and inform the Jackson library of dynamic type resolving,
the following two steps needs to be carried out:

### 1. Add Maven Dependency
#### Import OpenTMF Commons Dependencies
```xml
<dependencyManagement>
  <dependency>
    <groupId>org.opentmf.commons</groupId>
    <artifactId>opentmf-versions</artifactId>
    <version>RELEASE</version>
    <type>pom</type>
    <scope>import</scope>
  </dependency>
</dependencyManagement>
```
#### Import opentmf-622-v4-model Module
```xml
<dependency>
    <groupId>org.opentmf.commons</groupId>
    <artifactId>opentmf-622-v4-model</artifactId>
</dependency>
```

### 2. Configure the `ObjectMapper`
In order to benefit dynamic type resolving, you need to provide a primary `ObjectMapper` bean within
your microservice and call the registerExtensions method of this opentmf-622-v4-model library.

```java
@Configuration
public class JacksonConfig {

  @Bean
  @Primary
  public ObjectMapper objectMapper() {
    var objectMapper = JacksonUtil.getDefaultObjectMapper();
    Tmf622JacksonConfig.registerExtensions(objectMapper);
    return objectMapper;
  }
}
```

The registerExtensions method will automatically call its dependent model libraries'
registerExtensions method. Therefore, it is just enough to call one registerExtensions method
per OpenTMF model library.
